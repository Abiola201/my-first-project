# Netflix Movies & TV Shows Dashboard

## Project Overview
This project features an interactive dashboard analyzing Netflix's content catalog. The goal was to uncover insights regarding content distribution trends, top genres, and growth patterns over time.
![Dashboard Preview](Netflix%20dashoard.png)
## Key Insights Uncovered
* **Content Split:** Discovered the ratio of Movies vs. TV Shows on the platform.
* **Release Trends:** Identified the peak years for content additions.
* **Top Genres:** Highlighted the dominating genres driving the catalog.

## Tools & Technologies Used
* **Data Cleaning:** Excel Power Query (handling blank values, formatting date structures)
* **Data Visualization:** Power BI Desktop / Excel Architecture

## How to View
To interact with or edit the dashboard, download the `Netflix_Dashboard.pbix` file from this repository and open it using Power BI Desktop.
